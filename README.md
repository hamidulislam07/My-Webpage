# Premium Gaming Link-in-Bio Website

A responsive static website with a dark gaming / sci-fi background, subtle grid and scanline effects, neon blue-violet lighting, and slow staggered bottom-to-top entrance animations for the social cards.

## Files
- `index.html` — page content and link destinations.
- `styles.css` — background, responsive layout, hover effects, and animations.

## Customize before publishing
1. Open `index.html` in VS Code or Notepad.
2. Search for `Your Name` and replace it with your chosen brand/name.
3. Change the avatar initial `Y` to your own initial.
4. Replace the example URLs in each card with your actual Facebook, Instagram, YouTube, Discord invite, and email links.
5. Save and refresh `index.html` in Chrome to preview.

The links currently point to generic platform homepages. Do not publish until you replace them with your own URLs. For Discord, use your actual invite link if you want visitors to join your server. Change `mailto:hello@example.com` to your public contact email.

## Preview locally
Extract the ZIP and double-click `index.html`. No build tools are required. An internet connection is used for Google Fonts and Lucide icons; the website layout still works if those external libraries are unavailable.

## Free hosting with GitHub Pages
1. Create a free account at https://github.com/
2. Create a new public repository named `YOURUSERNAME.github.io` (replace `YOURUSERNAME` with your GitHub username).
3. Upload `index.html` and `styles.css` to the repository root. Do not upload only the parent folder.
4. Open **Settings → Pages** and publish from the `main` branch, root folder.
5. Wait for deployment and visit `https://YOURUSERNAME.github.io`.

Official guide: https://docs.github.com/en/pages/quickstart

A free `github.io` URL is enough for your Facebook and Instagram bios. A custom `.com` domain is optional and usually costs money.
